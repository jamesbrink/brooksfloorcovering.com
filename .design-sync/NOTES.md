# design-sync notes

- 2026-07-21 first sync. This repo is a static Astro site, not a React
  component library — user chose a **tokens + brand guidelines** scope. No
  component bundle, no `_ds_sync.json` anchor (off-script sync; a re-sync
  re-verifies everything, which is correct).
- Bundle is hand-built into `ds-bundle/` (gitignored): `styles.css` entry with
  brand utility classes mirroring the Tailwind names generated by the site's
  `@theme` in `src/styles/global.css`; self-hosted latin woff2 fonts fetched
  from Google Fonts (Inter 400–700, Playfair Display 600/700); tokens;
  guidelines authored from real site markup; 3 static preview cards.
- **Re-sync procedure**: if `src/styles/global.css` `@theme` tokens or the
  site's recurring patterns change, regenerate `ds-bundle/` to match (tokens ×2,
  styles.css utilities, guidelines), re-screenshot the 3 cards with Playwright
  to verify, then finalize_plan + upload the changed files and re-write the
  `_ds_needs_recompile` sentinel last. Do NOT run package-build.mjs.
- Preview cards verified 2026-07-21 via Playwright screenshots (fonts load,
  brand classes apply, gradient renders).
